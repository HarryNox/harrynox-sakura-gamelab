# 📁 images/ — 画像素材配置ガイド

ゲームで使用する画像ファイルをここに配置してください。
画像がない場合は自動的にプレースホルダー（文字アイコン）が表示されます。

---

## 📂 bg/ — 背景画像（オプション）

| ファイル名 | 使用場面 |
|-----------|--------|
| title_bg.jpg | タイトル画面 |
| battle_bg.jpg | 通常バトル |
| boss_bg.jpg | ボスバトル |
| event_bg.jpg | 道中イベント |

> 背景画像は現在CSSで代替されています。追加する場合はstyle.cssの各スクリーンの背景設定を変更してください。

---

## ⚠️ 注意事項

- 画像ファイルが見つからない場合、自動的にカラーコードによるプレースホルダーが表示されます
- ファイル名は**大文字のMBTIコード**（例: `INTJ.png`、`infj.png`は不可）
- 背景透過（PNG）を使うと見た目がきれいになります
